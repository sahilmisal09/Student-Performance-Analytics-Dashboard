# 04_Requirements

## Overview

This folder contains the complete requirements documentation for the **Student Performance Analytics & Decision Support System** project.

Requirements Engineering is the core Business Analysis activity that transforms business needs into detailed, testable, and traceable system requirements. These documents served as the foundation for designing the SQL data model, Python ETL pipeline, and Power BI dashboards.

---

# Folder Contents

## 01_Business_Requirements_Document (BRD)

**Purpose**

Captures the high-level business needs, objectives, stakeholder expectations, project scope, business problems, and expected outcomes.

**Contents**

- Business Background
- Business Objectives
- Problem Statement
- Project Scope
- Stakeholders
- Business Requirements
- Success Criteria
- Assumptions
- Constraints

**Deliverable**

Business Requirements Document (BRD)

## 02_Functional_Requirements_Document (FRD)

**Purpose**

**Contents**

- Filters and Drill-down Features

**Deliverable**

Functional Requirements Document (FRD)

## 03_Non_Functional_Requirements (NFR)

## 04_User_Stories

**Purpose**

Captures user requirements from the perspective of different stakeholders using Agile user story format.

Describes the interaction between users and the system for each major business process.

**Use Cases Included**

## 07_Requirement_Traceability_Matrix (RTM)

**Purpose**

Ensures that every business requirement is traced throughout the project lifecycle—from requirement definition to implementation and testing.

**Traceability Includes**

- Business Requirement ID
- Functional Requirement
- User Story
- Dashboard Component
- Test Case
- UAT Status

**Deliverable**

Requirement Traceability Matrix (RTM)

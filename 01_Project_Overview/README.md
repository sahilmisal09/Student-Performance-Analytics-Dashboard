# Project Overview

This folder contains the foundational documents created during the initiation phase of the **Student Performance Analytics & Decision Support System** project for **Mega Central High School**.

# Business Problem

Mega Central High School relied on manual spreadsheets and fragmented reports to monitor student academic performance. This resulted in:

- Delayed identification of academically at-risk students
- Limited visibility into subject and chapter performance
- Time-consuming manual reporting
- Inconsistent academic decision-making
- Difficulty tracking performance trends over time

---

# Proposed Solution

Develop a centralized **Student Performance Analytics & Decision Support System** that integrates:

- Python ETL Pipeline
- Microsoft SQL Server Database
- SQL-based business analysis
- Power BI Interactive Dashboards

The solution enables data-driven academic decision-making through automated reporting and interactive analytics.

---

# Expected Business Benefits

- Centralized academic reporting
- Early identification of high-risk students
- Improved curriculum analysis
- Faster reporting process
- Data-driven intervention planning
- Enhanced academic monitoring
- Better stakeholder decision-making
